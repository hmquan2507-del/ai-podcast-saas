# AI Podcast SaaS Specification v1.0

This directory is the official Source of Truth for the AI Talking Video Platform.

Code must follow these specifications.

If code and specs conflict, specs win.

---

## Purpose

This specification repository defines:

- Product vision
- Business rules
- Domain model
- Database design
- API contracts
- AI pipeline
- Rendering pipeline
- Frontend behavior
- Backend architecture
- DevOps
- Security
- Testing
- Release process

---

## Rule

No production feature should be implemented without a related specification.

Every sprint must follow:

1. Update specification
2. Review specification
3. Generate or update code
4. Test
5. Commit
